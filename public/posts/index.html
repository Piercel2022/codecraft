Introduction

Java is one of the most enduring and widely used programming languages in the world. Created by James Gosling at Sun Microsystems (now owned by Oracle) and released in 1995, Java has evolved from a simple language designed for interactive television to a powerful technology that powers everything from web applications to mobile devices and enterprise systems.
